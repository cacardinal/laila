# Tacit Lessons

Lessons from past mistakes — one entry per incident, dated. Keep entries short; the incident is the evidence, the lesson is the rule.

## Format

```
## [Lesson name] (YYYY-MM-DD)
**Incident:** what actually happened, one or two lines
**Lesson:** the rule that prevents a repeat
```

## Sample entry

## Verify the calendar before promising a date (2026-07-10)
**Incident:** Told Jordan a review call could happen "Thursday" from memory; the calendar had Sam's demo blocking that slot, and the reschedule cost a week.
**Lesson:** Dates come from the calendar read live, never from memory — check before any commitment leaves the building.
