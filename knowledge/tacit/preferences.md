# Preferences — How Alex Works

Tool and workflow preferences learned across sessions. Add an entry whenever Alex corrects the same behavior twice, or states a preference explicitly. Keep entries short and imperative — this file is read at session start when relevant.

Format: one `##` heading per preference area; each preference is a bolded rule plus optional context.

## Writing & Drafts

**Drafts go inline in chat, never straight into email drafts.** Alex wants to read and edit message text in the conversation first; only create an email draft after they approve the wording. (Stated 2026-06-12 after two unwanted draft creations.)

## Scheduling

**Never propose meetings before 10am.** Alex does deep work 7–10am and treats that block as untouchable. Suggest afternoon slots first when drafting scheduling replies. (Stated 2026-05-30.)

## Task Management

**One task, one home.** A task lives in either the task manager or a project tracking file, never both. When a task shows up in two places, ask which one is canonical and delete the other rather than syncing them by hand. (Learned 2026-07-03 after duplicate-task confusion.)
